[원문] SPHINCS-PRAGMA 비교 (Critical rod position) 왜 이런 에러가 나는가? / 기본적으로 ISC 계수는 burnup과 isotope density의 함수라고 볼 수 있음 (burnup축에 대해 2차 보간, isotope density에 선형) / 1. Control rod 의 delta cross-section이 macro로 처리되기 때문 / - 실제로는 control rod 삽입에 의해 micro xs가 변하며, 이에 의해 isotope별 연소가 달라짐 / 2. SPHINCS의 predictor-corrector에서 연소도 계산 시 predictor 값만 사용함 / - 마찬가지로 연소도 누적량이 달라지고, ISC 계수를 잘못 가져오게 됨. / 3. 기타 rodded form function 사용하지 않는 부분이나, CROMA-PRAGMA Gd 보간 차이, Xs library 차이 등..다양한 원인 존재 / 4. 부가적으로, T/H feedback이 없어서 ISC의 유무 차이가 매우 적음 (주기 말에서도 최대 100 pcm 수준) -> 1D 문제로 Sphincs-croma 비교해보기 (노드별 temp 가지고) / 대규모 수정이 필요 / MC와 비교할때는 stdev가 얼마인지 잘 생각해야한다 -> stdev range 내에 있을 확률이 sigma range 만큼이다 (=사실상있다) / 서펀트, 오픈MC는 파티클 수가 더 적으니 더 잘 고려해야한다.

[원문] 결론 RASBERY-SPHINCS는 상당히 유사한 결과를 보임 / ISC 부분을 제외한 나머지는 반사체 근방을 제외하고 매우 유사한 결과 (2~30 pcm 내외) 를 보임. / Hybrid에서 반사체에 대한 cross-section을 어떻게 처리하는지 조금 더 조사해볼 필요가 있음 / Depletion chain, fission yield 등이 다른 점이나, 세부적인 구현 등도 영향이 있을 것으로 추정됨. / 앞서 발견한 SPHINCS ISC implementation 상의 문제를 해결한 후 ISC 적용 결과를 비교 예정.
